# 课堂照片随机点名器

一个完全运行在浏览器本地的课堂随机点名工具。老师只需要选择一个装满学生照片的文件夹，页面就会按照片文件名生成点名名单，并以大屏投影友好的方式随机抽选学生。

项目不依赖框架、后端、数据库、API、CDN 或构建工具。下载后直接双击 `index.html` 即可使用，照片不会上传到任何服务器。

![课堂照片随机点名器界面预览](preview.png)

## 功能特点

- 一键选择班级照片文件夹，自动识别 JPG、PNG 和 WebP 图片。
- 图片文件名自动作为学生姓名，例如 `张三.jpg` 会显示为“张三”。
- 内置 8 位示例同学，没有照片时也能直接体验完整抽选流程。
- 提供滚动、翻牌、老虎机转盘三种抽选动画。
- 点击“开始点名”后高速切换，再次点击“停！”定格结果。
- 中奖结果以大幅照片、超大姓名和庆祝动画展示。
- 同一轮内自动排除已抽中的学生，避免重复点名。
- 待抽池清空后提示“本轮抽完”，可一键重置。
- 桌面端适配 1080P 投影，移动端可查看名单并完成抽选。
- 全部图片使用浏览器本地对象 URL 预览，不上传、不持久化。

## 快速开始

### 方式一：直接打开

1. 下载或复制整个项目目录。
2. 使用 Chrome 或 Edge 双击打开 `index.html`。
3. 页面会先加载 8 位内置示例同学。
4. 点击左上角“选择班级文件夹”导入真实学生照片。
5. 点击“开始点名”，再次点击“停！”完成一次抽选。

项目不需要安装依赖，也不需要启动本地服务器。

### 方式二：从 GitHub 下载

1. 打开 GitHub 仓库页面。
2. 点击绿色的 `Code` 按钮。
3. 选择 `Download ZIP`。
4. 解压后双击 `index.html`。

## 准备学生照片

建议为每个班级建立一个独立文件夹，并把学生照片直接放在里面：

```text
三年二班照片/
├── 张三.jpg
├── 李四.png
├── 王五.webp
├── 赵六.jpeg
└── 陈七.jpg
```

加载后，照片文件名去掉扩展名就是学生姓名：

| 文件名 | 页面显示姓名 |
| --- | --- |
| `张三.jpg` | 张三 |
| `李四.png` | 李四 |
| `王五.webp` | 王五 |

支持的图片格式：

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`

注意事项：

- 文件名就是点名时显示的姓名，请提前确认拼写。
- 不需要修改图片尺寸，但建议使用清晰的正方形或竖版照片。
- 如果同一学生同时放入了不同扩展名的重复图片，会被识别为两位同学。
- 文件夹内嵌套子目录中的支持图片也会被浏览器一并读取。
- 照片只在当前页面生命周期内可用，刷新页面后需要重新选择文件夹。

## 使用流程

### 1. 导入班级名单

点击页面左上角的“选择班级文件夹”，在系统文件夹选择框中选中照片文件夹。

加载完成后，顶部会显示：

```text
已加载 N 位同学
```

页面底部的班级名单也会同步替换。

### 2. 开始抽选

点击页面中央的大按钮“开始点名”。

此时：

- 按钮文字变为“停！”。
- 中央区域会以约 80ms 的间隔高速切换学生。
- 右侧“本轮结果”会持续记录已经抽中的学生。

### 3. 定格结果

再次点击“停！”，页面会立即从剩余待抽学生中随机选择一人，并弹出中奖卡片。

中奖卡片显示：

- 学生照片
- 超大字号姓名
- 本轮序号
- 剩余待抽人数
- CSS 庆祝动画

点击“继续点名”可关闭卡片并进入下一次抽选。

### 4. 重置一轮

当所有学生都被抽中后：

- 大按钮会显示“本轮抽完”并进入禁用状态。
- 点击“重置一轮”可以让全班重新进入待抽池。

重置只会清除本轮记录，不会重新加载照片。

## 三种动画模式

页面右上角可以切换动画风格：

| 模式 | 效果 |
| --- | --- |
| 滚动 | 中央照片和姓名高速切换 |
| 翻牌 | 卡片持续翻转，停止后显示中奖学生 |
| 转盘 | 老虎机式滚轮切换，模拟转盘停下 |

切换动画模式不会改变待抽池、已抽名单或本轮结果。

## 随机与去重规则

每次开始点名时，应用会从当前待抽学生中持续随机预览。

点击停止时：

1. 从当前待抽池中随机选择一名学生。
2. 将该学生加入本轮已抽名单。
3. 从待抽池中移除该学生。
4. 弹出中奖结果。

去重由学生的唯一 ID 实现，而不是仅依赖姓名判断。因此：

- 同一文件不会在同一轮中被抽中两次。
- 重置一轮后，所有学生重新变为可抽状态。
- 重新选择文件夹会清空本轮记录。

随机选择优先使用浏览器的 Web Crypto API：

```js
window.crypto.getRandomValues(buffer)
```

如果浏览器不支持该 API，会自动回退到 `Math.random()`。

## 数据与隐私

本项目不包含上传逻辑，也不会向任何服务器发送照片或名单。

具体行为：

- 使用 `URL.createObjectURL(file)` 在本地预览图片。
- 不使用 `FileReader` 读取并保存图片内容。
- 不使用后端、数据库或 API。
- 不使用 `localStorage` 保存照片。
- 不引入统计脚本、广告脚本或第三方字体。
- 重新加载文件夹或离开页面时，会调用 `URL.revokeObjectURL()` 释放旧地址。

浏览器仍然需要获得你主动选择文件夹的权限。选择后，浏览器会在当前页面内读取该文件夹中的支持图片，但不会上传它们。

## 技术实现

### 原生技术栈

- HTML5
- CSS3
- 原生 JavaScript
- Web File API
- Web Crypto API
- URL Object API

### 核心实现

- `<input type="file" webkitdirectory>` 负责打开系统文件夹选择框。
- `File.name` 提供照片文件名，正则去掉扩展名后作为姓名。
- `URL.createObjectURL()` 生成本地图片预览地址。
- CSS 自定义属性统一管理主题色、间距和字体。
- CSS `@keyframes` 实现翻牌、按钮脉冲、中奖卡片和庆祝碎片动画。
- `setInterval` 以 80ms 间隔切换随机预览。
- `Set` 保存本轮已抽学生 ID，保证同一轮不重复。
- `requestAnimationFrame` 用于中奖卡片的入场状态切换。

### 关键状态

`script.js` 中保存的主要状态包括：

| 状态 | 作用 |
| --- | --- |
| `students` | 当前加载的全部学生 |
| `selectedIds` | 本轮已经抽中的学生 ID |
| `selectedOrder` | 本轮中奖顺序 |
| `lastWinner` | 最近一次中奖学生 |
| `presentationMode` | 当前动画模式 |
| `isSpinning` | 是否正在抽选 |

### 抽选间隔

默认滚动间隔位于 `script.js`：

```js
const ROLL_INTERVAL = 80;
```

数值单位为毫秒。减小数值会加快切换，增大数值会减慢切换。

```js
function createSampleStudents() {
  return Array.from({ length: 8 }, (_, index) => {
    const name = `示例同学${index + 1}`;
    // ...
  });
}
```

### 修改主题颜色

颜色集中在 `style.css` 顶部的 `:root`：

```css
:root {
  --bg: #131417;
  --text: #f5f1e8;
  --accent: #ff6b2c;
}
```

### 修改滚动速度

在 `script.js` 中调整：

```js
const ROLL_INTERVAL = 80;
```

### 修改支持格式

图片扩展名规则位于 `script.js`：

```js
const IMAGE_EXTENSION = /\.(jpe?g|png|webp)$/i;
```

如果增加新格式，同时需要更新 `index.html` 中文件输入框的 `accept` 属性。

## 常见问题

### 选择了文件夹，但提示“未找到 JPG、PNG 或 WebP 图片”

请确认：

- 选择的是照片所在的文件夹，而不是单个文件。
- 文件扩展名确实是 `.jpg`、`.jpeg`、`.png` 或 `.webp`。
- 文件不是伪装成图片扩展名的其他格式。
- 使用的是 Chrome 或 Edge 桌面版。

### 显示人数和实际人数不一致

可能原因：

- 文件夹中存在不支持格式的图片。
- 同一学生放了多个不同扩展名的文件。
- 子文件夹中还有额外图片。
- 某些图片扩展名写错，例如 `.jpgg`。

### 姓名后面有编号或多余文字

页面直接使用文件名作为姓名。请在文件资源管理器中重命名图片，例如将：

```text
张三_最终版.jpg
```

改成：

```text
张三.jpg
```

然后重新选择文件夹。

### 刷新后为什么要重新选择文件夹

这是浏览器的安全限制，也是本项目的隐私设计。浏览器不会允许网页长期保留用户选择的本地文件权限，项目也没有使用 `localStorage` 保存文件内容。

### 能不能提前固定班级名单

当前版本以照片文件夹为名单来源。如果希望固定内置名单，可以修改 `script.js` 中的示例学生生成逻辑，但照片本身仍建议由老师通过文件选择框导入。

### 能否离线使用

可以。项目没有任何外部网络依赖，直接打开本地 `index.html` 即可运行。
